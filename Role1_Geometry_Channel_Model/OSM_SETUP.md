# Berlin OSM map setup

Role 1 needs an OpenStreetMap `.osm` file because the paper models the urban environment using OpenStreetMap building geometry.

## Required area

The antenna coordinates are approximately:

Latitude:
52.5608 to 52.5611

Longitude:
13.5038 to 13.5046

Your exported OSM file should contain the buildings around these coordinates.

## MATLAB file placement

Put:

    berlin.osm

in the same folder as the MATLAB files.

The project checks for this file before constructing the siteviewer.

## Important

The OSM file is not generated by the MATLAB code in this package.

You need to obtain/export the map data separately, then verify that the four antenna coordinates are inside the loaded map.

## Visual check

After running:

    S = build_role1_scenario;

MATLAB should display the urban geometry and four antenna sites.

You should be able to visually identify:
- Tx1
- Tx2
- Rx1
- Rx2
- surrounding buildings

If a site appears outside the loaded map, fix the OSM coverage before doing channel calculations.
